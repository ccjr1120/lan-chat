# 首页（App）

## 路由

App 启动页（`MaterialApp.home`），`HomePage(storage)`。

## 页面结构

首页由 `_View` 派生三个互斥视图（`_host` 是否存在、`_joining`）：

- 首页（`home`）：大标题、说明、设备名胶囊（「当前设备 · 名称 ✎」，点击改名，新名称下次创建会话生效）和一张会话卡（`_sessionCard`）。卡片上半部分为创建会话（标题、说明、连接示意、失败原因、渐变按钮），「或」分隔线下方只有一个「加入会话」按钮。
- 会话已开启（`hosting`）：邀请卡（运行状态、二维码、主地址、其他地址折叠、刷新、加入方式）、进入会话渐变按钮与结束会话文字按钮；不显示加入与改名入口。
- 加入会话（`joining`）：附近会话卡（刷新按钮、实时列表，点击即加入）与「输入会话地址」文字按钮；手动地址在弹窗中输入，支持 IP、IP:端口与完整 http 地址，地址无效时在输入框内提示。
- 返回：两个子视图都有返回按钮（macOS 在正文标题行左侧，其他平台为 AppBar leading），`PopScope` 拦截系统返回键 / 侧滑。加入视图直接回首页；会话视图弹出结束会话确认，确认后停止服务并回到首页，取消则留在会话视图。首页不拦截返回。
- 结束会话前确认：说明所有设备会断开、传输会中断，历史和文件保留。从聊天页返回首页时服务保持运行（回到会话视图）。
- 创建会话进行中（`_starting`）禁用「加入会话」按钮与改名入口，避免并发操作。
- macOS 所有宽度均使用原生产品标题，无重复 AppBar，正文标题行右侧显示设置菜单；其他平台 AppBar 标题随视图显示产品名 / 会话已开启 / 加入会话，右侧为设置菜单。

## 交互状态

| 状态 | 表现 |
| --- | --- |
| `_starting` | 按钮显示进度并禁用 |
| `_host != null` | 显示地址卡片；监听 `pendingRequests`，逐个弹出 `JoinRequestDialog` |
| 发现中且无结果 | 加入视图附近会话区显示搜索中与进度指示 |
| 发现失败 | 附近会话区显示失败原因 |

## 数据来源

- `AppStorage.settings`：设备名、访问模式、主题选项（默认 system）。
- `HostSession`：地址、在线设备、待确认请求。
- `LanDiscovery`：发现的主机。进入加入视图时启动，返回首页或进入客户端聊天页时停止，从客户端聊天页返回加入视图时重新启动。

## 接口依赖

无直接 HTTP 调用。连接时创建 `ClientSession`，并在聊天页内调用 `/api/info` 和 `/ws`。

## 实现入口

`lib/ui/pages/home/home_page.dart`

## 桌面布局与主题

三个视图在所有宽度都使用最大宽度 620 的居中单列，首页只有一张会话卡，宽屏不再分栏。加入视图附近会话区最小高度 220，避免搜索结果出现时页面跳动；空态 / 列表切换使用 AnimatedSwitcher。会话卡创建区内的 ConnectionDiagram 展示当前设备、对应平台图标、手机 / 浏览器及同一网络说明，不表示实际连接状态；示意宽度 < 340 时缩小图标与间距，长设备名最多两行，溢出省略且支持完整名称 tooltip。WorkspaceBackground 以 SizedBox.expand 撑满 body，内容不足一屏时背景仍覆盖整个窗口。

正文标题行和设置菜单位于整体滚动内容中，适配低高度窗口。macOS 无论窗口宽度均不显示重复产品 AppBar，产品名由原生标题呈现；其他平台使用本地化 AppBar。设置菜单包含主题（system / light / dark）与语言（跟随系统 / 简体中文 / English），初始默认均为 system，并保存用户选择。设备名胶囊保留改名入口。页面、弹窗、连接示意、状态及错误提示从当前 locale 的 AppLocalizations 读取，中英文默认随系统语言，也可在设置菜单中指定；设备名保持原值。不改变主机生命周期与 LanDiscovery 内部逻辑。

页面区块以 FadeSlideIn 错峰入场（200ms easeOutCubic，延迟 0–100ms：标题 → 说明 → 各卡片），区块 key 由区块名与当前视图组成，在首页 / 会话已开启 / 加入会话之间切换时重放入场，同一状态内的重建（启动中、错误、设备变化）不重放。主操作按钮（创建会话、进入会话、连接设备）使用 GradientFilledButton 的 primaryGradient 渐变，启动中退化为禁用态并显示进度；「加入会话」为 OutlinedButton 次级样式（最小高度 50，与渐变按钮同高），「输入会话地址」为 TextButton。
