# 首页（App）

## 路由

App 启动页（`MaterialApp.home`），`HomePage(storage)`。

## 页面结构

- macOS 首页所有宽度均使用原生产品标题，无重复 AppBar；正文标题行右侧显示设置菜单，加入模式左侧显示返回按钮。其他平台 AppBar 显示产品名 / 加入会话标题及设置菜单。设备改名统一使用设备身份卡。
- 默认首页：大标题、说明、独立设备身份卡、创建会话主卡和加入会话次级入口；窄屏内容最大宽度 620，宽度 ≥ 900 时最大宽度 1440。
- 主机未启动：创建会话说明、当前设备 ↔ 手机 / 浏览器连接方式示意和渐变主按钮，启动中禁用按钮，失败原因保留在卡片内。
- 主机已启动：邀请卡（运行状态、二维码、主地址、其他地址折叠、刷新、加入方式）、进入会话渐变按钮、加入其他会话入口与结束会话文字按钮。
- 结束会话前确认：说明所有设备会断开、传输会中断，历史和文件保留。返回首页仍保持服务运行。
- 加入模式：附近会话优先（刷新、设备名、地址、加入箭头），手动地址输入位于折叠区域，支持 IP、IP:端口与完整 http 地址。
- 主机运行时进入加入模式，会显示“你的会话仍在运行”并提供返回入口。

## 交互状态

| 状态 | 表现 |
| --- | --- |
| `_starting` | 按钮显示进度并禁用 |
| `_host != null` | 显示地址卡片；监听 `pendingRequests`，逐个弹出 `JoinRequestDialog` |
| 发现中且无结果 | 显示进度指示 |
| 发现失败 | 副标题显示错误 |

## 数据来源

- `AppStorage.settings`：设备名、访问模式、主题选项（默认 system）。
- `HostSession`：地址、在线设备、待确认请求。
- `LanDiscovery`：发现的主机，切到客户端模式时启动，切回主机模式时停止。

## 接口依赖

无直接 HTTP 调用。连接时创建 `ClientSession`，并在聊天页内调用 `/api/info` 和 `/ws`。

## 实现入口

`lib/ui/pages/home/home_page.dart`

## 桌面布局与主题

宽度 ≥ 900 时使用操作双栏（最大宽度 1440）：左侧创建 / 邀请面板，右侧设备身份和加入会话卡片，比例 7:4、间距 24。窄屏回到最大宽度 620 的单列，加入模式仍使用同一整体内容宽度。独立宣传 banner、三步引导与桌面统计卡移除。创建会话卡片内的 ConnectionDiagram 展示当前设备、对应平台图标、手机 / 浏览器及同一网络说明，不表示实际连接状态；示意宽度 < 340 时缩小图标与间距，长设备名最多两行，溢出省略且支持完整名称 tooltip。

正文标题行和设置菜单位于整体滚动内容中，适配低高度窗口。macOS 无论窗口宽度均不显示重复产品 AppBar，产品名由原生标题呈现；其他平台使用本地化 AppBar。设置菜单包含主题（system / light / dark）与语言（跟随系统 / 简体中文 / English），初始默认均为 system，并保存用户选择。设备身份卡保留改名入口。页面、弹窗、连接示意、状态及错误提示从当前 locale 的 AppLocalizations 读取，中英文默认随系统语言，也可在设置菜单中指定；设备名保持原值。不改变主机生命周期与设备发现逻辑。

页面区块以 FadeSlideIn 错峰入场（200ms easeOutCubic，延迟 0–100ms：标题 → 说明 → 各卡片），区块 key 由区块名、模式与主机是否运行组成，在主机 / 加入 / 会话就绪之间切换时重放入场，同一状态内的重建（启动中、错误、设备变化）不重放；设备身份卡、加入会话入口卡与「会话仍在运行」卡在桌面悬停时 HoverLift 微提升。主操作按钮（创建会话、进入会话、连接设备）使用 GradientFilledButton 的 primaryGradient 渐变，启动中退化为禁用态并显示进度；加入会话入口保持 OutlinedButton 次级样式。
