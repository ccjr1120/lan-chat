# 首页（App）

## 路由

App 启动页（`MaterialApp.home`），`HomePage(storage)`。

## 页面结构

首页是单屏单列（最大宽度 620，整体可滚动），不再有"会话已开启 / 加入会话"子视图和返回按钮：

- 标题与"当前设备 · 名称"（只读文本；改名在设置菜单的"设备名称"里内联完成，新名称下次创建或加入会话时生效）。
- 创建会话卡：一句说明、失败原因、一个 FilledButton「创建会话」。点击后启动 `HostSession` 并直接进入聊天页。
- 附近的会话：标题行带刷新按钮，下方是实时列表（点击即加入）；空态显示搜索中与进度，发现失败时显示失败原因。列表最小高度 160，避免结果出现时页面跳动。
- 输入会话地址：列表下方的文字按钮，点击后就地展开输入框（支持 IP、IP:端口与完整 http 地址，右侧箭头或回车连接，无效地址在输入框内提示）。
- macOS 所有宽度均使用原生产品标题，无重复 AppBar，正文标题行右侧显示设置菜单；其他平台 AppBar 标题为产品名，右侧为设置菜单。

## 交互状态

| 状态 | 表现 |
| --- | --- |
| `_starting` | 创建按钮显示进度并禁用，附近会话列表项禁用 |
| 创建失败 | 创建卡内显示失败原因，可重试 |
| 主机在聊天页中 | 首页持有 `HostSession`，监听 `pendingRequests`，逐个弹出 `JoinRequestDialog`（弹在聊天页之上） |
| 从聊天页返回 | 主机会话随即结束，重新开始设备发现 |

## 数据来源

- `AppStorage.settings`：设备名、访问模式、主题 / 语言选项（默认 system）。
- `HostSession`：创建会话后的待确认请求。
- `LanDiscovery`：发现的主机。首页启动时开始；创建会话或连接设备期间停止，返回首页后重新开始。

## 接口依赖

无直接 HTTP 调用。连接时创建 `ClientSession`，并在聊天页内调用 `/api/info` 和 `/ws`。

## 实现入口

`lib/ui/pages/home/home_page.dart`

## 视觉与动效

背景为 WorkspaceBackground 纯色，无渐变、光晕或连接示意图。页面区块以 FadeSlideIn 错峰入场（200ms easeOutCubic，延迟 0–80ms：标题 → 当前设备 → 创建卡 → 附近会话）。页面、状态及错误提示从当前 locale 的 AppLocalizations 读取，中英文默认随系统语言；设备名保持原值。不改变主机生命周期与 LanDiscovery 内部逻辑。
